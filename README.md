## 📱 Main Project

### 🔥 BurningMate (버닝메이트)
> AI 기반 목표 관리 & 동기부여 서비스

#### 📌 문제 정의
- 많은 사람들이 목표를 세우지만
  - 구체적인 계획 부족
  - 동기 부족으로 지속 실패

#### 💡 해결 방식
- AI가 개인 맞춤 목표 및 할 일 생성
- 보상 시스템(포인트, 리워드)으로 지속성 강화

#### 🏗️ Architecture
- **Frontend**: Flutter (Riverpod)
- **Backend**: Supabase (PostgreSQL, RPC, RLS)
- **AI**: Gemini API (2.5 Flash)
- **Analytics**: Firebase Analytics / Crashlytics
- **Remote Control**: Firebase Remote Config

#### ⚙️ 핵심 기능
- AI 목표 생성 (SMART 기반)
- AI 할 일 추천 시스템
- 포인트 기반 보상 시스템
